What I've built

Job Radar: an AI job-matching pipeline

Free code does the volume and AI does the judgment. A GitHub Actions pipeline reads job boards through their APIs, filters and pre-scores every posting with rules, and hands only the promising ones to Claude through a remote MCP server I wrote. Every AI answer passes validation that blocks invented numbers or experience, and each run reports its own health.
