Job Radar

An AI job-matching pipeline that reads the market every morning and hands me only the roles worth my time.

The problem

Checking job boards by hand took hours a week and still missed roles. Running every posting through an AI model would have meant a monthly API bill.

What I built

Free code does the volume: it reads company job boards through their APIs in parallel, filters by role, place, pay and seniority, and pre-scores with rules. A remote MCP server I wrote lets Claude score the shortlist and draft tailored resumes, with no API bill.

How I know it works

Every AI answer passes validation that rejects invented numbers or experience. More than 110 automated tests run on each change, and each run logs its timing, errors and cost to a health report that alerts me when something breaks.

  1. 540+company job boards read in parallel
  2. ~74,000postings checked each weekday in 3–4 minutes
  3. $0rules filter and pre-score every job
  4. MCPClaude scores fit and tailors a resume
  5. 1 taptracker card, alert and dashboard update

Apartment Price Tracker

Watches the apartments you care about and tells you the moment rent hits a new low or a new unit is listed.

The problem

Rent changes constantly, and listing sites don't tell you when a unit you want gets cheaper. Refreshing floor-plan pages by hand is easy to forget and impossible to compare over time.

What I built

A tracker that reads each complex's listing page four times a day, records every unit's size, rent and move-in date, and keeps the price history in the repo itself. There's no server and nothing to leave running.

Built for others

It's a template: copy the repo, list your complexes, add a Discord webhook or Gmail app password, and it runs free on GitHub Actions. Sites with different layouts can be matched with a few patterns, and the tests ship with sample data.

  1. 4× a daychecks every listing page you add
  2. Historysaves each unit's rent and move-in date
  3. Comparespots new all-time lows and new units
  4. Alertemail or Discord, with a price chart
